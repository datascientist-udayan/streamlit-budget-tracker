# streamlit-budget-tracker

# 💸 Personal Budget Tracker

An interactive web application built with **Python** and **Streamlit** to track monthly income, manage expense categories, and visualize savings metrics in real time.

🔗 **Live App:** [View on Streamlit Community Cloud](<YOUR_LIVE_APP_URL>)

---

## ✨ Features

- **Interactive Sidebar Controls:** Adjust monthly income and expense sliders (Rent, Food & Groceries, Utilities, Entertainment) with instant updates.
- **Key Financial Metrics:** Automatically calculates **Total Expenses**, **Net Savings**, **Savings Rate (%)**, and **Remaining Daily Budget**.
- **Visual Breakdown:** Displays a dynamic bar chart alongside a structured expense summary table powered by Pandas.

---

## 🛠️ Tech Stack

- **Frontend & App Framework:** [Streamlit](https://streamlit.io/)
- **Data Processing:** [Pandas](https://pandas.pydata.org/)
- **Language:** Python 3.11+
